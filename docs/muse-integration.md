# Muse 网页账号接入

桌面入口：双击项目根目录的 **Start-Canvas-Desktop.cmd**，在打开的 Draw studio 窗口中进入项目，
点击画布顶部的显示器图标，再选择 Muse。Muse 页面会直接显示在画布内；首次使用可在该面板登录已有账号。
网页预览入口 **Start-Canvas.cmd** 只能显示“请在桌面版打开”的提示，因为 Muse 网页不允许嵌入普通网页。

生成入口：画布顶部 **远程连接 → 算力设置 → Muse 账号 → 使用 Muse 生成**。
图片节点使用 Muse 图片，视频节点使用 Muse 视频；填写提示词，
按需连接图片、视频和音频参考素材后运行。当前生成结果仍为图片或视频，不提供音频生成模式。
切换账号时，在该专用窗口退出当前账号再登录，并先处理原账号未完成的任务。

## 运行方式

这是本机网页适配器，不是 Meta 官方生成 API。仅使用用户主动登录的
[Muse 官网](https://muse.ai) 账号，与 RunningHub AI 应用、RunningHub 工作流、云端 ComfyUI 分开。
账号需要实际具备 Muse 访问权限及相应生成额度，适配器不会绕过等候名单或地域限制。

本机启动器会启动 Vite preview 和 Muse 中间件；开发环境由 `npm run dev` 启动。
浏览器以独立、可见的 Chromium 窗口运行，Windows 优先使用已安装的 Microsoft Edge，
备用为本机已安装的 Playwright Chromium，不会在登录时自动下载浏览器。
Tauri 窗口仍需同时运行画布本机服务 `http://127.0.0.1:1420`；独立打包应用目前不内置此 Node 服务。

登录和网页操作可在桌面画布的 Muse 面板中进行，该面板显示真实网页视图，不按截图频率刷新。
画布生成仍通过本机后台适配器运行；直接在 Muse 网页聊天框发送的内容没有画布节点关联，
不会自动保存到画布。要让结果回到画布，请从画布节点点击运行。
已有会话可继续复用；正常连续生成保留当前页面和聊天。
新启动的 Chromium 窗口启用 sandbox，不再附加 --no-sandbox。
专用窗口意外关闭后，连接检查会使用同一份本机配置重新打开原聊天；已提交任务只恢复查询。
主动点击“断开”会关闭自动重连，下次点击登录再启用。配置和登录状态保留。

发送用户原始提示词和混合图片／视频／音频参考，素材按画布连线顺序上传。
不拼接生成说明、文件清单、比例文字或任务编号；需要指定比例时可在原始提示词中表达。
适配器不额外设置参考素材数量、单个或合计文件字节数、结果保存大小、生成等待时长上限。
平台账号权限、额度、可上传格式以及网站自身限制仍以 Muse 实际页面为准；
上传遵循页面真实文件选择器的 `accept` 和 `multiple` 设置，并显示网站返回的错误。
结果尺寸以平台实际返回为准。
独立负面提示词仍不支持；需要的要求可写入主提示词。

参考文件使用原始二进制请求流上传到本机临时文件，生成请求只携带任务所属的上传句柄。
新上传流程不把整个文件转换成 Base64 塞入 JSON。失败的接收流会清理未完成文件；
任务处理结束后，会清理对应的临时参考文件。

## 任务和结果

- 首次发送前保存稳定任务 ID 和“可能已发送”记录，发送按钮只点击一次。
- 发送前等待网页加载、工作区初始化及连接状态就绪；上传后、点击发送前再次检查。
- 用户消息气泡出现仅说明网站本地显示了草稿，不代表服务器已接收。明确送达状态或本回合的助手回复才确认接收。
- “Still sending／仍在发送”在没有结果时继续等待；同一已校验回合已有实际可解码结果时确认接收并保存，避免旧发送标签挡住写回。“未确认送达”或发送失败仍显示可恢复问题，不自动重发。
- 服务串行处理任务，正常连续生成复用同一浏览器页面和同一聊天，不为每个任务新开页面或聊天。
- 已提交但未完成的任务先恢复查询，不自动切换账号、重放提示词或再次点击发送。
- 刷新画布继续查询；本机服务重启后恢复原会话读取，不重放提示词。
- 浏览器关闭或本机服务重启后，按原任务 ID 自动重新连接并查询；恢复失败会保留“恢复查询”入口。
  网站明确未送达、发送失败、消息不匹配等问题不会触发自动重发。
- 原会话地址无法确认时，可凭当前窗口中唯一的原任务消息恢复观察；找不到或标记重复则说明原因，不自动重发。
- 没有生成总时长限制，不依据等待时长伪造完成进度。
- “停止任务”撤下本机待发队列并中断当前本机等待；等待恢复的任务也可停止。
  已经被 Muse 接收的任务可能继续运行，停止本机任务不代表网站取消成功。
- 查询结果阶段停止会保留 Muse 页面。浏览器操作开始前复用一个空白备用标签；
  若停止时上传、填写或发送操作仍未结束，立即关闭操作页来阻止迟到发送，并在已有备用标签打开原聊天。
  不创建新话题，不为每次生成新开窗口。
- 停止记录持久化；即使停止请求早于创建请求到达，后到的请求也不会重新入队。
  取消后的上传、发送和下载迟到响应不会重新激活或完成该任务。
- 新任务通过本机保存的提示词摘要及此前消息摘要定位本回合，不向 Muse 发送追踪标记。
  只读取对应用户消息之后、下一条用户消息之前的助手媒体回复；消息缺失或不匹配时不取整个聊天的结果。
  带旧标记的历史任务仍可按旧标记恢复。
- 消息识别包含真实的 `group/msg` 用户行，仍排除其中的上传预览。首次精确验证后，
  在同一真实消息元素存续期间允许前面的虚拟列表节点卸载；目标消失、复用或修改时不猜测匹配。
  提交前及确认送达时滚动到最新消息，只有可见的停止按钮才表示网站仍在生成。
- 排除用户上传预览、视频封面和网页 HTML，并检查目标媒体类型及真实媒体尺寸。
- 保存实际二进制图片/视频，回填原节点、素材记录和生成历史。
- 任务详情保留原 Muse 会话链接；浏览器账号需要与原生成账号一致。
- 不同项目的异步响应互相隔离，不将旧项目结果写入当前画布。

## 本机数据

Windows 位置：`%LOCALAPPDATA%/DrawStudio/muse`。
`browser-profile` 保存持久浏览器配置和登录会话；`jobs.json` 保存任务元数据、摘要、
私有回合摘要（历史任务可含旧标记）和结果清单；`references` 保存接收中的临时参考文件；`media` 保存二进制结果。
`browser-session.json` 仅保存自动重连开关和原聊天地址，不包含密码或 Cookie。
原始提示词按画布已有的生成任务规则保存在项目中；本机服务的 `jobs.json`
不另外保存原始提示词或参考文件 Base64，也不向前端暴露任意磁盘路径。
登录信息留在本机浏览器配置中；不导出 Cookie 文件、不记录密码、不上传到第三方代理。
“断开”关闭专用浏览器上下文；本机浏览器配置仍保留，下次打开时可恢复已有登录状态。

本机接口只接受 localhost / 127.0.0.1 / ::1 的同源画布和指定 Tauri 来源，
媒体只能从 Muse/Meta 相关域名读取，下载重定向也逐跳检查。
结果文件通过任务清单查询，参考文件通过任务所属的上传句柄查询。

## 验证范围和维护

自动测试覆盖提交去重、提交响应丢失、断点恢复、跨项目隔离、部分下载失败、
混合参考素材、流式上传和清理、回合结果隔离、真实媒体类型核对、输入验证和本机访问边界。
这些验证没有执行真实账号的付费生成，不代表真实 Muse 图片或视频生成已验收。
网站 DOM 改动可能需要更新适配器；无法识别的结果保留原任务供恢复。
