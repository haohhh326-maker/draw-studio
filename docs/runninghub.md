# RunningHub 与画布

## 使用

1. 刷新画布，点击右上角齿轮，分别配置「云端 ComfyUI」与「RunningHub」。
2. RunningHub 的 CN/AI 账号密钥分别填写、单独长期保存在本机。输入框留空保留已有密钥，「保存并验证」会验证改动的站点；更换站点会恢复本站密钥。
3. 点击「管理工作流」，输入自己的 RunningHub 工作流 ID 或同站分享链接，点击「读取并添加工作流」。读取的是完整 API 节点图，会展示节点数、模型/权重、分类、素材、参数和输出，并支持查看隐藏密钥后的完整节点结构。也可以填写平台 ID 后在高级导入中读取 API JSON。
4. 正常工作流会自动识别分类及画布绑定并加入目录；无法确定的自定义输出才需要确认。工作流里检测到 API Key 字段时，会另外打开「工作流 API Key」填写界面。这些节点密钥与 RunningHub 平台账号密钥分别保存，只有执行副本会注入节点密钥。
5. 点击顶部小云朵选择 RunningHub，在图片、视频、音频或文本节点中选择刚添加的工作流，再点击生成。

## 隔离与保存

- 原云端工作流目录保持独立。RunningHub 初始列表为空，只使用用户添加的工作流；中国站与国际站也分别管理。
- 切换算力会分别记住节点的工作流与参数，保留提示词、连线、素材、已有结果和任务。首次切换到另一算力需要重新选择工作流。
- 切换 RunningHub 站点后会清除其他站点的当前选择，需要从本站列表重新选择；另一站的工作流配置仍保留。
- 已提交任务使用自己的执行器、站点及工作流快照查询、恢复和取消，不随顶部算力切换而改投另一服务。
- 结果返回原节点，仍需右键主动添加到资产库。
- 两套连接配置存于本机。API Key 不放进生成任务快照或项目导出的连接信息中。结果下载不携带 API Key。

工作流节点密钥也适用于原云端目录。读取或选择有密钥要求的工作流会单独提示填写；需要修改时点击生成面板的钥匙图标。没有密钥字段的工作流不会要求填写。

AI 应用链接或 ID 可读取平台公开的输入与输出合同并映射到画布。平台没有公开内部节点图时，界面明确标为「AI 应用公开输入/输出」，不会把公开参数合同称作完整工作流图。

## 接入实现

RunningHub 工作流通过 `getJsonApiFormat` 读取，按画布绑定生成 `nodeInfoList`，使用 `task/openapi/create` 提交并保存平台 taskId。结果通过 `task/openapi/outputs` 查询；804 表示等待，805 表示失败。平台提供的错误会显示到任务及原节点；没有平台进度时不生成虚假百分比。提交结果不确定时保留原任务，不自动重复创建。

浏览器通过画布同源代理访问固定的 RunningHub API；桌面版使用原生 HTTP。代理只接受支持的官方站点及 API 路径，限制上传请求大小，结果下载采用流式传输并阻止内网地址及重定向。

## 验证与官方协议
